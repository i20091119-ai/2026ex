# 우리가 그린 그림 넣는 곳

이 폴더에 **정해진 이름**으로 그림(PNG)을 넣으면 게임이 그 그림으로 바뀌어요.
그림이 없는 자리는 지금 모습(실루엣) 그대로 나와요.
그래서 **한 장씩 천천히** 바꿔도 괜찮아요.

## 사람

| 파일 이름 | 누구 | 나오는 곳 |
|---|---|---|
| `hero.png` | 주인공 | 1·3·4·5·6장, 이야기 |
| `mate.png` | 독립운동가 동료 | 1·3장 이야기, 4·6장 |
| `kimgu.png` | 김구 | 2장 퀴즈, 이야기, 6장 |
| `yu.png` | 유관순 | 4장, 6장 |
| `police.png` | 일본 경찰 | 1·3·4장, 들켰을 때 |
| `police-look.png` | 일본 경찰이 **이쪽을 쳐다볼 때** (없어도 돼요) | 1장 |
| `captain.png` | 일본 헌병대장 | 5장 |
| `captain-look.png` | 헌병대장이 **공격하려고 노려볼 때** (없어도 돼요) | 5장 |

- **서 있는 온몸**을 그려요. 발끝이 그림 아래쪽에 닿게요.
- 주인공은 **오른쪽을 보게** 그려요 (오른쪽으로 달려가니까요).
- `-look` 그림이 없으면, 쳐다볼 때 그림 둘레가 **붉게 빛나요.**
- 배경은 **투명**해야 예뻐요. 종이에 그려서 사진을 찍었다면
  선생님께 보내 주세요. 배경을 지워서 넣어 드려요.

## 배경

| 파일 이름 | 어디 |
|---|---|
| `title.png` | 시작 화면 |
| `ch1.png` | 1장 · 골목길 |
| `ch2.png` | 2장 · 비밀 아지트 |
| `ch3.png` | 3장 · 미로 바닥 |
| `ch4.png` | 4장 · 광장 |
| `ch5.png` | 5장 · 마지막 싸움 |
| `ch6.png` | 6장 · 광복의 날 |

- **가로로 긴** 그림이 좋아요 (예: 1600 × 900).
- 글씨와 사람이 잘 보이게, 게임이 배경을 **살짝 어둡게** 덮어요.
- 시작 화면 배경에는 제목·Start 글씨를 **빼고** 그려요. (게임이 위에 써 줘요)

## 넣는 방법

1. GitHub 에서 이 `images` 폴더로 들어가요
2. **Add file → Upload files** 로 그림을 올려요 (이름을 꼭 표에 맞게!)
3. **Commit changes** 를 누르면 1~2분 뒤 게임 주소에 바로 반영돼요
4. 한 파일 버전(`독립을향하여.html`)에도 넣으려면 `python3 build.py` 를 다시 해요
