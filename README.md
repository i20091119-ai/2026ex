# 독립을 향하여

> 서진모둠 (서진 · 조찬우 · 박윤진) 이 만든 역사 게임

일제강점기를 배경으로, 6개의 임무를 하나씩 해결하며 독립을 이루는 1인용 게임이에요.

## 게임 하는 방법

### 1. 인터넷으로 하기
깃허브 페이지 주소를 브라우저에 입력하면 바로 게임이 켜져요.

### 2. 파일로 하기 (인터넷이 없어도 돼요)
이 폴더를 내려받고 `index.html` 파일을 두 번 눌러서 여세요.

## 조작 방법
- 키보드
- 마우스
- 아케이드 조종기 (방향 스틱 1개 + 버튼 8개)

세 가지 모두로 조작할 수 있어요.

## 폴더 안내
| 파일 | 하는 일 |
|---|---|
| `index.html` | 게임 화면의 뼈대 |
| `css/style.css` | 게임을 예쁘게 꾸미는 곳 |
| `js/game.js` | 게임이 움직이게 하는 곳 |
| `GAME_PLAN.md` | 학생들이 쓴 게임 기획서 |
