# 독립을 향하여

> **서진모둠** (서진 · 조찬우 · 박윤진) 이 만든 역사 게임

1940년대 일제강점기를 배경으로, 여섯 개의 임무를 하나씩 해결하며
광복을 이루는 1인용 게임이에요.

---

## 게임 여는 방법 (세 가지)

### 1. 깃허브 페이지로 열기 (아케이드 기계에 추천)

인터넷이 되는 곳이라면 주소만 입력하면 바로 게임이 켜져요.

```
https://i20091119-ai.github.io/2026ex/
```

**처음 한 번만 켜주면 돼요:**

1. 깃허브에서 이 저장소로 들어가요
2. 위쪽 **Settings** 를 눌러요
3. 왼쪽에서 **Pages** 를 눌러요
4. **Source** 를 `Deploy from a branch` 로 두고,
   **Branch** 를 `claude/elementary-web-game-tool-9334xc` / `/ (root)` 로 고른 뒤 **Save**
5. 1~2분 기다리면 위 주소로 게임이 열려요

### 2. 파일 하나로 열기 (인터넷이 없어도 돼요)

**`독립을향하여.html`** 파일 하나만 USB 에 담아 옮기면 돼요.
두 번 눌러서 열면 바로 게임이 시작돼요.

### 3. 여러 파일로 열기 (고칠 때)

`index.html` 을 두 번 눌러서 열면 돼요.
코드를 고친 뒤에는 아래를 실행해 한 파일 버전을 다시 만들어요.

```
python3 build.py
```

## ⚠️ 조종기가 안 움직일 때 꼭 읽어주세요

### 게임을 **창 안의 창**에서 열면 조종기를 못 써요

다른 페이지 안에 끼워 넣어진 작은 창(iframe)에서 게임을 열면,
브라우저가 **보안 때문에 조종기 사용을 막아요.**

**해결 : 게임 주소를 새 탭 주소창에 직접 붙여넣어 여세요.**

게임 안에서도 이 상황이면 화면에 안내가 나와요.

### 조종기 스위치 두는 자리

아케이드 조종기(JOYTRON EX REVOLUTION V1) 왼쪽 위에 스위치가 두 개 있어요.

| 스위치 | 어디로 | 뜻 |
|---|---|---|
| 기종 선택 (왼쪽) | **XINPUT / NS** (위쪽) | PC 엑스인풋 방식 |
| 스틱 신호 (오른쪽) | **DP** (가운데) | 십자키 방식 |

네 가지 조합(XINPUT+LS / XINPUT+DP / XINPUT+RS / DINPUT+DP)을
모두 시험해서 전부 되도록 만들었지만, 위 설정이 가장 확실해요.

### 그래도 안 되면 : 조종기 맞추기

게임이 조종기 신호를 **직접 배우게** 할 수 있어요.

1. 아래 세 곳 중 아무 데서나 조종기 확인 화면을 열어요
   - 시작 화면 오른쪽 위 **조종기 확인**
   - 게임 화면 맨 아래 **조종기 연결됨** 칸
   - 6번 버튼(잠시 멈춤) 화면의 **조종기 확인·맞추기**
2. **조종기 맞추기** 를 눌러요
3. 화면이 시키는 대로 스틱을 밀고 버튼을 눌러요 (모두 12번)
4. 끝! 설정이 저장돼서 다음에 켜도 그대로예요

## 조작 방법

세 가지 방법으로 모두 조작할 수 있어요.

| | 움직이기 | 버튼 |
|---|---|---|
| **아케이드 조종기** | 방향 스틱 | 버튼 8개 |
| **키보드** | 방향키 / WASD | 아래 표 참고 |
| **마우스** | 화면 아래 안내판의 화살표 | 안내판의 버튼 |

| 버튼 | 하는 일 | 키보드 |
|---|---|---|
| 1 | 점프 | `Ctrl` 또는 `J` |
| 2 | 말걸기 | `Alt` 또는 `K` |
| 3 | 공격 | `Space` 또는 `L` |
| 4 | 다음 | `Shift` 또는 `Enter` |
| 5 | 소리 크기 | `Z` |
| 6 | 잠시 멈춤 | `X` |
| 7 | 처음으로 | `C` |
| 8 | 글씨 크기 | `V` |

화면 아래 안내판에서 **어느 버튼이 무슨 일을 하는지 항상 볼 수 있고**,
진짜로 버튼을 누르면 그 칸에 불이 들어와요. 연결 확인에도 쓸 수 있어요.

## 게임 이야기와 미션

| 장 | 이야기 | 미션 | 점수 |
|---|---|---|---|
| 1장 | 비밀 편지 | 경찰이 뒤돌았을 때만 달려서 편지 전달 | +10 |
| 2장 | 김구 선생님과의 만남 | 역사 퀴즈 3개 맞히기 | 한 개당 +5 |
| 3장 | 태극기 지키기 | 미로에서 태극기 5장 찾아 안전한 곳으로 | +10 |
| 4장 | 만세운동 준비 | 사람들에게 태극기 나누어 주기 | 한 명당 +3 |
| 5장 | 독립을 향하여 | 일본 헌병대장과의 싸움에서 승리 | +30 |
| 6장 | 광복의 날 | 태극기를 흔들어 새벽을 맞이하기 | — |

모두 성공하면 **80점**이에요.

**목숨은 3개**예요. 일본 경찰에게 들키면 목숨이 하나 줄고 그 장을 다시 해요.
목숨을 모두 잃으면 게임이 끝나요.

## 폴더 안내

| 파일 | 하는 일 |
|---|---|
| `index.html` | 게임 화면의 뼈대 |
| `독립을향하여.html` | **한 파일짜리 게임** (USB 로 옮길 때) |
| `build.py` | 여러 파일을 한 파일로 합치는 도구 |
| `css/style.css` | 게임을 꾸미는 곳 |
| `js/sound.js` | 소리 (파일 없이 직접 만들어요) |
| `js/input.js` | 조작 (키보드 · 마우스 · 조종기) |
| `js/missions.js` | 미션 보관함 |
| `js/ch1.js` ~ `js/ch6.js` | 1장부터 6장까지의 미션 |
| `js/game.js` | 게임 전체를 이끄는 곳 |
| `GAME_PLAN.md` | 학생들이 쓴 게임 기획서 |

만들 때 쓴 것은 **HTML · CSS · 자바스크립트뿐이에요.**
설치할 것도, 인터넷에서 받아오는 것도 하나도 없어요.
